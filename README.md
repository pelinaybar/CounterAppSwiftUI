# SwiftUI Counter

A compact SwiftUI learning project demonstrating state-driven UI updates and basic user interaction.

![Swift](https://img.shields.io/badge/Swift-F05138?logo=swift&logoColor=white)
![SwiftUI](https://img.shields.io/badge/SwiftUI-0D96F6?logo=swift&logoColor=white)

## Learning Focus

- SwiftUI view composition
- Local state management
- Button actions
- Live previews
- Basic Xcode project structure

## Run

1. Clone the repository.
2. Open `SwiftUIGiris.xcodeproj` in Xcode.
3. Select an iOS simulator.
4. Build and run with `⌘R`.

## Status

This is a small educational project created to practice SwiftUI fundamentals.
